# Example sources

**Romeo and Juliet.docx** contains selected passages from William Shakespeare’s *Romeo and Juliet*: the Prologue and part of Act II, Scene II. The text is public domain. The transcription comes from [Project Gutenberg ebook 1513](https://www.gutenberg.org/ebooks/1513), credited there to the PG Shakespeare Team. [Source text and its terms](https://www.gutenberg.org/cache/epub/1513/pg1513.txt).

The Word formatting and screenshot annotations were prepared for Nitpick’s documentation. The notes illustrate the interface; they are not changes to Shakespeare’s text. `romeo-and-juliet.json` stores the excerpt for reproducibility. Regenerate the Word file with `npm run sample:romeo`.

Other documents in this directory are synthetic software-test fixtures created for this project. They contain no imported personal essays.
